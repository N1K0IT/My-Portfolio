# Grundforløb 2 – Datatekniker med speciale i programmering (TEC)

Dette repository samler mine projekter, øvelser og opgaver fra **Grundforløb 2** på datateknikeruddannelsen med speciale i programmering på TEC. Formålet er at give et samlet overblik over min faglige udvikling, og hvad jeg kan indtil videre, imens jeg søger læreplads.

## Hvad jeg samlet har lært på GF2

### Programmering og softwareudvikling
* **Grundlæggende programmeringslogik:** Arbejde med datatyper, variabler, operatorer, betingelser (`if/else`, `switch`) og løkker (`for`, `while`, `foreach`).
* **Struktur og genbrug af kode:** Opdeling af kode i metoder/funktioner og grundlæggende principper inden for objektorienteret programmering (klasser, objekter, properties og indkapsling).
* **Datahåndtering:** Brug af arrays, lister/collections og simpel filhåndtering eller dataopbevaring.
* **Fejlhåndtering og debugging:** Validering af brugerinput, brug af `try/catch` og fejlfinding med breakpoints og debugger.

### Værktøjer og arbejdsmetoder
* **Versionsstyring:** Oprettelse af repositories, commits, branches og håndtering af kode med **Git** og **GitHub**.
* **Udviklingsmiljøer:** Dagligt arbejde i ** Visual Studio / Visual Studio Code **.
* **Problemløsning og planlægning:** Nedbrydning af en opgave i mindre delproblemer, simpel flowcharting/pseudokode og dokumentation af egen kode.

### IT-forståelse og infrastruktur (grundlæggende)
* **Netværk og systemer:** Grundlæggende forståelse for IP-adresser, netværksopbygning, operativsystemer og hvordan applikationer afvikles.
* **Sikkerhed og god praksis:** Fokus på ren, læsbar kode, meningsfulde variabelnavne og grundlæggende sikkerhed omkring brugerinput og data.
